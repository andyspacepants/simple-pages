1

Install Warp

~5 min · free

Warp is a modern terminal — think of it as a code-aware command line that was built in the AI era. The free tier is plenty for what we're doing.

  1. Go to warp.dev and click Download for Mac. It'll grab the right build for your chip (Apple Silicon or Intel) automatically.
  2. Open the .dmg and drag Warp into Applications.
  3. Launch Warp from Applications. macOS will ask you to confirm opening an app from the internet — say yes.
  4. Sign in with email or Google. Pick the Free plan when asked.
  5. You should see a clean window with a prompt blinking at you.
What you're looking at: Warp is where Claude Code will live. Every conversation, every project — they all start with you typing in this window.
2

Install Claude Code

~5 min · uses your Anthropic account

This is the actual tool. One command in Warp installs it — no Node, no Homebrew, no admin password. Auto-updates are handled for you.

curl -fsSL https://claude.ai/install.sh | bash

That'll churn for a minute. When it finishes, close Warp and reopen it so the new claude command is on your PATH, then verify with:

claude --version

You should see a version number print out. If you do — you're 90% of the way there.

If claude isn't found after restarting Warp: the installer placed it at ~/.local/bin/claude. Run echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc, then close and reopen Warp. One-time fix.
Quick aside

The terminal isn't scary.

It looks intimidating, but honestly — you only really need a handful of commands to get around. Claude Code helps you with the rest. Here's the cheat sheet:

mkdir
Make a directory — like creating a new folder.
cd
Change directory — like double-clicking into a folder.
cd ..
Go back up one folder. (Two dots = "the folder above this one.")
ls
Stands for "list." Shows what's inside the current folder.
pwd
"Print working directory." Tells you where you are when you're lost.
clear
Wipes the screen clean. Doesn't delete anything — just gives you a fresh view.
3

The sanity check

~5 min · the magic moment

This is the moment you'll remember. We're going to make a folder, start Claude inside it, and ask it to do something. Don't skip — this confirms your whole stack works and gives you a feel for the loop.

In Warp, run these one at a time:

# Make a test folder on your desktop
mkdir ~/Desktop/unleash-test
cd ~/Desktop/unleash-test

# Start Claude Code in this folder
claude

The first time you run claude, it'll walk you through signing in. Use the same Anthropic account you use for Claude.ai — Pro or Max plan covers Claude Code at no extra charge.

Once you're in, paste this prompt and hit enter:

Make a file called hello.txt that introduces
yourself, lists three things you can help with,
and tells me one thing you find genuinely
interesting about helping a sales executive
think more clearly.

Watch what happens. It'll think for a second, write the file, then tell you it's done. Open the folder in Finder — hello.txt will be sitting there, real, on your actual disk.

That's it. That's the unlock. Claude isn't trapped in a chat window anymore — it's working in your file system, with persistent context, building real artifacts you can keep, share, and iterate on. That's why the chat-only experience felt limiting.

To exit Claude Code, type /exit or hit Ctrl+C twice. Your work stays in the folder.
